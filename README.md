## Slime Odyssey

## Theme
As a slime, collect all the flowers (coins) before contacting the human warrior.

## How to play
- jump = space bar&nbsp;
- you can go down by pressing [down key + jump] from platforms
- human warrior follows the slime (in BFS and DFS style)
- chicken and duck move with their own brain (once it gets contacted by anyone, it runs away)

## Playable Map
- 2 playable maps (Clearing the first map can continue to the second level)
- 1 admin map (check all the user info (total score, history))
